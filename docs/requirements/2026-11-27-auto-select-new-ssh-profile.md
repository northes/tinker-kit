# 工具内新增 SSH 主机后自动选中

## 背景与目标

用户在工具中的 SSH 选择器打开配置管理器并新增主机后，需要返回当前工具继续使用该主机。新增保存成功后由发起管理器的选择器立即选中新主机，减少再次查找和选择的操作。

## 需求条目

1. 所有工具内复用的 SSH 选择器，在其打开的配置管理器中手动新增 SSH 配置并成功保存后，立即选中新配置。
2. 只更新打开配置管理器的那个选择器；同一页面或其它工具中的 SSH 字段保持原值。
3. 批量导入 SSH 配置后不自动切换当前选择。
4. 保存失败时不改变选择。

## 已定决策

- 覆盖所有工具内 SSH 选择器，确保共享组件行为一致。
- 自动选中只应用于手动新增成功的配置。批量导入可能新增多条且也可能只更新，因此导入后不自动选择。
- 选择范围限定为发起此次管理器操作的单个选择器，避免影响其它字段。

## 非目标

- 不改变独立 SSH 配置管理器的默认选择行为。
- 不在编辑已有 SSH 配置或批量导入后自动切换选择。
- 不调整 SSH 配置表单、导入流程或其它 SSH 选择行为。

## 验收标准

- 从任一工具 SSH 选择器打开管理器，手动新增并成功保存后，原选择器显示并持有新配置 ID。
- 其它 SSH 选择器的值不因这次新增而变化。
- 新增保存失败时，当前及其它选择器的值均不变。
- 批量导入完成后，当前选择器仍保留导入前的选择。

## 待定问题

- 无。
