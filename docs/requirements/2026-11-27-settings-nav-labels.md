# 设置页左侧菜单命名对齐页面内容

## 背景与目标

设置页左侧分类菜单（`frontend/src/components/SettingsPage.tsx` 的 `SETTINGS_CATEGORIES`）有几个分类名比实际内容宽：`连接` 下只有 SSH 配置管理与 known_hosts，`工作区` 下只有标签设置，`数据与安全` 下只有配置导出/导入/重置（没有任何安全相关设置）。菜单名让人猜不到里面有什么，需要改成与内容一致的短名。

## 需求条目

1. 分类 `connections` 的显示名由「连接」改为「SSH」，英文 `Connections` 改为 `SSH`。
2. 分类 `workspace` 的显示名由「工作区」改为「标签」，英文 `Workspace` 改为 `Tabs`。
3. 分类 `data` 的显示名由「数据与安全」改为「配置管理」，英文 `Data & security` 改为 `Configuration`。
4. 改名后分类名与其面板内唯一分组标题同名（`SSH` / `标签` / `配置管理`），窄屏下分类标题与分组标题会重复出现，需要消除重复。
5. 只改显示文案，分类 ID、`settings.categories.*` key、分类顺序和面板结构保持不变。

## 已定决策

- 范围取「顺带统一」：除用户点出的 `连接→SSH`，同时处理同类名称宽于内容的 `工作区→标签`、`数据与安全→配置管理`；`常用偏好→通用` 暂不做。
- 中英文同步修改，保持一一对应。
- 重复标题的消除方式：删除设置面板里仅窄屏可见（`max-[701px]`/`min-[701px]:sr-only`）的分类标题块。窄屏上方 Select 触发器已经显示当前分类名，且每个面板本身都有分组标题，这个标题块纯属重复。
- 分类名直接沿用用户确认的措辞（`标签`、`配置管理`），不为了避开与分组标题同名而改叫 `标签页`、`配置`。

## 非目标

- 不重命名 `settings.categories.*` 的 key，也不重排分类顺序。
- 不调整各分类内部的分组、设置项或布局。
- `自动化与通知`、`常用偏好`、`工具`、`关于` 的命名保持不变。

## 验收标准

- 设置页左侧菜单依次显示：常用偏好、标签、工具、自动化与通知、SSH、配置管理、关于；英文为 Preferences、Tabs、Tools、Automation & notifications、SSH、Configuration、About。
- 进入 `SSH`、`标签`、`配置管理` 分类时，面板内不会出现两个相同的标题。
- 窄屏（宽度 ≤ 700px）下仍能从上方 Select 得知当前分类，面板内容与小屏布局不出现空洞或错位。
- 中英文资源文件中 `settings.categories.*.title` 的 key 结构保持一致。

## 待定问题

- 无。
