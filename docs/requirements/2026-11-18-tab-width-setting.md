# 设置中可调整标签宽度

状态：已对齐。实现时以本文「已定决策」与「需求条目」为准。

## 背景与目标

工作区标签栏的宽度现在是写死的两档 CSS 变量：无图标 `--workspace-tab-width: 128px`，根元素带 `data-show-tab-icons='true'` 时改成 `148px`（`frontend/src/styles/foundation.css:7,39`）。用户没法按自己的标题长度和屏幕宽度调。

目标：在设置页「工作区」里加一项标签宽度，既能选固定宽度，也能让整栏跟着最长标题自适应。

## 需求条目

1. 设置页新增「标签宽度」：先选模式（固定宽度 / 随内容自适应）。
2. 固定模式用预设档位：112 / 128 / 148 / 168 / 196 px，默认 128。自适应模式下档位控件不可用（隐藏或禁用）。
3. 固定模式的值是**基础宽度**：打开「显示标签图标」时仍各自再宽 20px，即现有 128 → 148 的关系保持不变。
4. 自适应模式：标签栏所有标签同宽，宽度取当前标签栏里最长标题所需的宽度（含序号、图标、关闭按钮占位），clamp 到 112–240 px（基础宽度，图标档同样 +20px）。
5. 自适应要跟着这些变化重算：标题内容变化（重命名、序号变化）、标签增删、显示图标开关、语言切换、窗口宽度变化导致的换行无关项。
6. 自适应模式下的宽度变化直接生效，不加宽度过渡动画（现有补位/让位动画保持不变，不能被宽度变化带得抖）。
7. 配置持久化：Go `Config` 新增 `tabWidthMode`（`"fixed"` / `"auto"`）与 `tabWidth`（整数像素，基础宽度）。默认 `fixed` + 128，未配置时与今天的观感完全一致。
8. 归一化：`tabWidthMode` 非法值回 `fixed`；`tabWidth` 不在档位里时取最近的合法档位。

## 已定决策

### 取值与控件

- 控件用 `ChoiceGroup`，与「编辑器字号」「关闭按钮方式」等现有设置项同款，不引入输入框与非法值处理。
- 固定档位固定为 112 / 128 / 148 / 168 / 196，默认 128。
- 支持「固定值 + 自适应」两种模式；不做「每个标签各自宽度」，自适应时整栏同宽，视觉整齐。

### 与图标档的关系

- 设置项是基础宽度，`showTabIcons` 打开时仍额外 +20px。这样现有开启图标的用户（128 → 实际 148）升级后外观不变。
- 实现上把 `data-show-tab-icons` 的 148px 改成 `calc(var(--workspace-tab-width) + 20px)`，不要在别处再写一份宽度常量。

### 入口与范围

- 只在设置里调，不加标签栏右键菜单、不加拖动标签栏边缘改变宽度的交互。
- 标签的其它交互（拖动排序、关闭按钮显隐、重命名、固定、补位动画、选中高亮）都不变。
- 空白标签、设置标签与工具标签继续同宽，不给某类标签单独设宽度。

### 持久化

- 沿用 Go `Config`，两个新字段：`tabWidthMode`（string，`"fixed"` | `"auto"`，默认 `"fixed"`）与 `tabWidth`（int，基础像素，默认 128）。
- Go 导出类型变化后必须重新生成 `frontend/bindings/`，不手工编辑。
- 归一化只做上面两条：非法 mode 回 `fixed`，宽度取最近合法档位；自适应模式不影响存储的 `tabWidth`（切回固定时用它）。

## 非目标

- 不给每个标签单独宽度，不做按标签类型分宽度。
- 不改标签高度、字号、图标尺寸、关闭按钮样式与渐隐宽度。
- 不新增快速调整入口（右键菜单、拖动边缘、快捷键）。
- 不改自适应以外的排版：外边距、圆角、选中高亮色块逻辑都不动。
- 不改网络测试/镜像管理等其它设置项。

## 验收标准

- 设置页「工作区」里有「标签宽度」：模式二选一；固定模式能选五个档位，自适应模式下档位不可用。
- 默认（未改过设置）启动时标签宽度与改动前一致：无图标 128、有图标 148。
- 固定模式选 168、不开图标 → 所有标签等宽 168；再打开图标 → 188。
- 自适应模式：标签栏所有标签同宽；把某个标签重命名成更长的名字，整栏一起变宽；把长名标签关掉，整栏能缩回去；极端长标题下不超过 240（有图标时 260），极短标题下不小于 112。
- 自适应模式在切换标签时宽度变化不产生抖动或动画冲突，现有补位动画仍正常。
- 设置写入配置并重启后保持；手改配置文件成非法值（如 `tabWidthMode: "wide"`、`tabWidth: 137`）时加载不报错，回落为 `fixed` + 最近档位（137 → 128）。
- 重新生成的 `frontend/bindings/` 与 Go 结构一致，前端构建与 `go test ./...` 无新增失败。
