# 数据表头与 SSH 路径间距

状态：已对齐。实现时以本文「已定决策」与「需求条目」为准。

## 背景与目标

镜像列表、SSH 文件列表、端口列表、端口转发列表用的是同一套平铺数据表：行是隔行淡底、两端圆角，没有行间分割线。表头却还是贴在页面底色上的默认栏，和行不是一套。

SSH 文件管理里，路径栏和下面的表头直接相接，没有空隙。

目标：这些数据表的表头改成设计系统里已经写明的淡底横栏；SSH 路径栏和列表之间留出一档空隙。

## 需求条目

1. 下列表格的表头改成不透明淡底横栏，文字用辅助色，两端圆角与所在表的数据行同一档（`rounded-md`），不要底部分割线，悬停整行时不要再给表头铺一层行悬停色：
   - 镜像管理的镜像列表
   - 镜像详情里的层列表
   - SSH 文件管理的文件列表
   - 端口工具的端口列表
   - 端口工具的端口转发列表
2. 吸顶的表头在滚动时必须盖住滚过的行。圆角外侧仍是页面底色，不能透出下面的行。
3. SSH 文件管理的路径栏与下方列表区之间留 12px（`gap-3`）。空隙在文件列表滚动容器外面：滚动后表头仍吸在列表区顶部，空隙不被滚走，也不把表头重新贴回路经栏。
4. 这条空隙是路径栏和下面整块内容区之间的间距，空态、加载、出错时也同样留着，不单在有表头时才出现。

## 已定决策

- 表头底色是 `color-mix(in oklch, var(--muted) 45%, var(--background))`。这些表落在页面工作面上，混入的是 `--background`，不是 JSON 表用的 `--card`。
- 表头行使用 `hover:bg-transparent`，避免 `TableRow` 默认的行悬停盖住淡底横栏。
- 吸顶表头的 `thead` 继续用 `bg-background`，只把淡底和圆角放在 `th` 上。这样圆角切掉的角仍是页面底色，滚动内容不会从角上漏出来。
- 不改排序按钮、列宽拖动、勾选列和行的斑马纹。表头只补这一层横栏。
- JSON 表格预览和 JSON 流水线输出表已经用 `json.css` 做成同一类淡底横栏（混入 `--card`）。它们不算漏改，这次不动。
- 端口工具是唯一还没改、又和镜像 / SSH 文件列表同一结构的工具表。服务、网络测试、时间、URL 等是普通条纹行，没有这列表头，不纳入。

## 非目标

- 不改 JSON 表头的现有样式，也不把 `--card` 混色改成 `--background`。
- 不改 `frontend/src/components/ui/data-table.tsx`。当前没有工具引用它。
- 不把镜像详情的层列表改成吸顶。
- 不调整表头高度、字号、排序按钮外观，也不改边缘渐隐的 `top-10`。
- 不改数据行的斑马纹、圆角、悬停和选中。

## 验收标准

- 镜像列表、镜像层表、SSH 文件列表、端口列表、端口转发列表的表头是一块连续的淡底横栏，两端圆角与偶数行一致，没有底部分割线，列名是辅助色。
- 吸顶表头滚过数据行时，行不会从横栏或圆角外侧透出来。
- SSH 路径栏和下面的列表（以及空态、加载、出错）之间有 12px 空隙；列表滚动时，空隙仍留在路径栏下方，表头吸在列表区顶部。
- JSON 表头外观与改动前一致。
