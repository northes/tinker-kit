# SSH 配置与主机指纹弹窗

## 背景与目标

`$impeccable critique` 对「SSH 配置」导入列表和「应用内 SSH 主机指纹」的评分是 24/40。两个弹窗都是在管理信任的连接，行样式却不是一套：导入列表是隔行淡底，指纹列表是横线，滚动边缘还是齐切。用户确认指纹列表应跟导入列表用同一套数据行，并且 P1、P2 一起做。

## 需求条目

1. **指纹列表改成数据行（P1）**：`SSHKnownHostsDialog` 去掉 `divide-y`。行使用与本机导入行相同的隔行淡底：`index % 2 === 1` 时 `bg-muted/30`，两端 `rounded-md`，悬停 `hover:bg-accent`。不要 `border-b`。列表用 `ul` / `li`。该弹窗的 `ScrollArea` 加上已有的 `edgeOverlay`，不要自绘渐变，也不要 `scrollFade` mask。
2. **导入列表的边缘渐隐要真正盖住裁切（P1）**：本机导入弹窗已经传了 `edgeOverlay`，实拍顶行仍被页眉底边齐切。修根因，不在弹窗里再叠一条渐变。视口与渐变层目前都是 `z-index: 0`；若渐变画在视口下面或没对准视口裁切边，就在 `ScrollArea` / `foundation.css` 的既有边缘渐变上修。滚到头的一侧高度仍收到 0，滚动条仍在渐变上面。其它调用方的默认位置不变。
3. **搜索和分段标题吸顶（P1）**：SSH 配置列表里，搜索框吸在滚动视口顶部；「已添加的配置」「本机 SSH config」的标题行（含该行上的刷新、新增）吸在搜索框正下方。吸顶块用弹窗实底，不用 mask 把标题淡掉。顶部 `edgeOverlay` 让到吸顶块之下。搜索仍是现在的即时过滤，不要改成回车才过滤。某个分段因搜索被隐藏时，不渲染它的标题。
4. **「已导入」不再是按钮（P1）**：已存在的本机配置用不可聚焦的 `Badge` 显示现有「已导入」文案。未导入行仍是原来的描边「导入」按钮。
5. **指纹能核对（P1）**：每行主指纹是短形式：有 `SHA256:` 前缀时保留前缀，再加上哈希前 12 个字符和省略号 `…`；没有前缀时取整串前 12 个字符，超长才加省略号。行内只显示这一份完整指纹，等宽、可换行、可选择。复制完整指纹，不复制短形式。行上的复制按钮已被第 16 条移进「更多」。成功只用 toast（`toast.copied`，插值用短指纹）；失败用 `toast.copyFailed`，且不得再提示成功。按钮文案、`aria-label`、`title` 保持 `common.copy`，图标保持 phosphor `Copy`（Regular），不要换成对勾或「已复制」。编辑态里的指纹同样可复制。没有 `navigator.clipboard` 时走失败提示。
6. **行内删除不再常驻红色（P2）**：指纹行的删除按钮用 `text-muted-foreground`，不要 `text-destructive`。确认框保持危险态和现有文案。
7. **指纹地址与导入列表同一种主机+端口（P2）**：单一主机（纯主机名、IP、或 `[host]:port`）显示为 `host:port`，省略端口时按 22。含逗号、空白、`*`、`?`、`!` 的匹配项保持原文，不编造端口。行内只显示这一种形式，不再另起一行重复原文。不改存储值，编辑框和删除确认仍用原始 `hosts`。
8. **明文警告挪到填密的地方（P2）**：列表眉题只留「所有工具共用的连接参数。」/ “Connection parameters shared by every tool.” 表单眉题不变。密码与私钥的明文警告放在认证字段上方，密码模式和私钥模式都显示，导入的配置也显示。中英文同步。
9. **导入之后页脚用「关闭」（P2，已被第 17 条取代）**：原来按本次打开是否导入成功，在 `common.close` 和 `common.cancel` 之间切换。第 17 条改为列表页脚始终是「关闭」。
10. **本机导入行补上与已保存行相同的横向内边距（P1 附属）**：本机导入行补 `px-2`。已保存行的悬停色不要改。
11. **列表指纹升到正文（P2）**：指纹列表里那一份完整指纹用 `text-xs text-foreground`，保留等宽、换行和可选中。不要把短指纹画回行里。短形式仍只用于复制成功的 toast。
12. **测试连接在行上看得见（P2）**：`testingID` 对上的已保存配置，名称旁显示 Spinner，并禁用该行编辑。成功和失败仍走现有 toast。菜单里的测试项可以留下，但进行中不能只出现在已经关掉的菜单里。
13. **指纹行主操作只留复制（P2，已被第 16 条取代）**：原来行上保留带文字的复制，编辑和删除进「更多」。第 16 条改为铅笔进入详情，复制和删除进菜单，编辑不再出现在菜单里。`keyType` 和 `marker` 仍用 `Badge variant="outline"`。
14. **明文警告用警告语义（P3）**：句子和位置不变。不要再用和跳板说明一样的灰色正文。用图标加上现有 warning 表面（`border-warning/30`、`bg-warning/10`、`text-warning`），不要只靠颜色。
15. **指纹列表可搜索（P3）**：有记录时，列表上方放与配置弹窗相同的 `ToolSearchField`，即时过滤，匹配原始 hosts、展示地址、类型、备注和指纹。无匹配时给空状态。搜索吸顶，顶部边缘渐隐让到搜索框下。不要批量删除，不要改成回车才搜。
16. **详情行尾只留铅笔和更多**：能进入详情的行（已保存 SSH 配置、指纹记录）行尾只有两个 `ghost` `icon-sm` 控件：铅笔进入该行详情，「更多」用现有 `DotsThreeOutlineVertical`，`aria-label` 继续用 `sshProfiles.moreActions`。不要带文字的行尾按钮，也不要 `text-[11px]`。指纹铅笔的可访问名称用 `settings.sshKnownHostsEditTitle`。指纹菜单只有「复制」（`common.copy`，phosphor `Copy` Regular，仍复制完整指纹，成功和失败 toast 规则不变）和危险项「删除」；菜单里不再有「编辑」。已保存配置的铅笔仍是编辑；菜单仍是测试连接、本机导入时的从本机更新、删除，不把编辑放进菜单。本机 SSH config 行不动：未导入仍是描边「导入」，已导入仍是徽章。
17. **返回列表，列表页脚一律关闭**：两个详情的页脚次按钮都是「返回列表」。配置弹窗继续用 `sshProfiles.back`；指纹弹窗复用这句已有文案，不新建同义 key。相对刚打开详情时的内容有改动才确认放弃，没有改动直接回列表且不保存。配置弹窗继续用现有放弃确认。指纹弹窗用 `ConfirmDialog`，文案只加 `settings.sshKnownHostsDiscardTitle`、`settings.sshKnownHostsDiscardDescription`、`settings.sshKnownHostsDiscardConfirm`，中英同步；说明写的是返回列表会丢掉修改，不要写成关闭弹窗。脏检查只比较能编辑的主机匹配项、公钥和备注。列表页脚两个弹窗都用 `common.close`，与本次是否导入无关；删掉 `importedThisOpen` 和只为它存在的赋值，不留死状态。右上角关闭和点击遮罩不改：配置弹窗仍走现有脏检查关闭，指纹弹窗仍直接关闭并丢掉编辑态。表单内的测试连接、从本机更新、详情里的复制指纹不动。标题和说明仍随详情切换。`settings.sshKnownHostsEdit` 不再被引用时从两份 locale 删除。

## 已定决策

- 先统一成斑马纹并补上边缘渐隐；指纹列表不是有意用横线。
- P1 和 P2 一起做。
- 指纹列表跟本机导入行用同一套淡底、圆角和悬停，不改成 `hover:bg-muted/50`。
- 两个弹窗分给两个子代理：指纹弹窗只改 `SSHKnownHostsDialog`，不改 locale；文案改动全部由 SSH 配置弹窗的代理写入两份 locale。
- 边缘渐隐的共享实现只由 SSH 配置弹窗的代理修改。
- 不把这两个对话框改成虚拟列表。
- 复评后的三件 P2 和两件 P3 一起做：指纹字号、行上测试进度、指纹行只留复制、警告语义、指纹搜索。其中「指纹行只留复制」已被第 16 条取代。
- 指纹弹窗的新文案只加在 `settings.sshKnownHosts*`；SSH 配置弹窗不改 locale。第 17 条的放弃确认文案仍按此规则。
- 能进入详情的列表行尾只留铅笔和更多。复制、测试、从本机更新、删除进菜单；编辑不再在菜单里重复。本机 SSH config 的「导入」文字按钮和「已导入」徽章不动。
- 两个详情的页脚次按钮都叫「返回列表」。相对刚打开详情时有改动才确认放弃，没有改动直接回列表。列表页脚一律「关闭」。
- 表单里的测试、从本机更新、指纹复制，以及右上角关闭和点击遮罩，保持现在的行为。指纹弹窗从这两处离开仍直接关闭，不增加未保存确认。标题和说明仍随详情切换。

## 非目标

- 不改导入按钮的下载图标。
- 不改配置弹窗搜索的即时过滤时机，不加「只看未导入」或批量导入。指纹列表可以搜索，但不做批量删除。
- 不改指纹的编辑字段、删除确认流程、加载和空态。第 17 条只增加「返回列表」的未保存确认。
- 不改表单内的测试连接、从本机更新、详情里的复制指纹。
- 不改右上角关闭和点击遮罩：配置弹窗仍走现有脏检查关闭；指纹弹窗仍直接关闭并丢掉编辑态。
- 不改分段标题上的刷新、新增，也不改其它管理弹窗。
- 不改 Go、bindings、工具注册、托盘。
- 不改工作区标签条上已有的未提交修改。
- 不新增第二套滚动渐变或局部 CSS 文件。

## 验收标准

- 指纹列表无横线，偶数序号行有淡底，两端有 `rounded-md`；滚动时上下溢出使用 `edgeOverlay`，滚到头的一侧不留渐变。
- SSH 配置列表滚进本机配置后，仍能看见搜索和当前分段标题；顶行文字不是被页眉齐切。
- 「已导入」不能被 Tab 聚焦，也不能再触发导入。
- 复制指纹写入的是完整指纹；剪贴板失败时没有成功 toast。
- 行内删除不是危险色；确认框仍是危险操作。
- 单一主机显示 `host:port`（默认 22），通配和多主机匹配项不被改写成假端口。
- 列表眉题不再出现明文警告；认证字段上方能看到该警告。中英文都有。
- 两个弹窗的列表页脚都是「关闭」，与本次打开是否导入过无关。代码里不再留 `importedThisOpen`。
- 列表指纹是一份 `text-xs` 正文色全文，不是 10px 灰色，也没有第二行短指纹。
- 测试进行中，对应配置名称旁有 Spinner，该行编辑不可用。
- 已保存配置行尾仍是铅笔和更多；更多里没有「编辑」，有测试连接，本机导入的配置还有从本机更新，以及删除。
- 指纹行尾是铅笔和更多，没有带文字的「复制」按钮。更多里有复制和删除，没有编辑。复制仍写入完整指纹；成功、失败 toast 规则不变。删除确认仍在。
- 本机 SSH config 未导入行仍是描边「导入」，已导入行仍是不可聚焦的「已导入」徽章。
- 两个详情页脚的次按钮都是「返回列表」，主按钮仍是「保存」。
- 指纹详情未改字段时点「返回列表」直接回列表，不弹确认。改过主机匹配项、公钥或备注后再点，先确认；确认后回列表且不保存，取消确认仍留在详情。
- 配置详情原有的未保存确认仍在：「返回列表」和关闭弹窗都会问。
- 指纹详情有未保存修改时，右上角关闭和点击遮罩仍直接关闭，不弹放弃确认。
- 中英文案同步。铅笔的可访问名称用已有编辑标题；不再被引用的 `settings.sshKnownHostsEdit` 从两份 locale 删除。
- 明文警告带图标和 warning 表面，不是纯灰色说明。
- 指纹列表能按主机、类型、备注、指纹过滤；搜不到有空状态。
- `wails3 task common:frontend:run SCRIPT=build` 通过。
