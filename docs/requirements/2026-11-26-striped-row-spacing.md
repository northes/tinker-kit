# 斑马纹数据行左右留白

## 背景与目标

URL 解析结果的字段标题和复制按钮离条纹边缘过近。统一现有斑马纹数据行的水平内边距，让普通结果行更易扫描，同时维持多列表格的紧凑密度。

## 需求条目

1. 普通结果行、设置列表和对话框列表的行内左右留白各为 12 px（`px-3`）。同一列表的奇数行和偶数行使用相同留白。
2. 紧凑数据表格的首尾列外侧留白各为 8 px（Tailwind `ps-2`、`pe-2` 或等效的逻辑属性）。表头沿用正文首尾列的边缘留白。勾选框和拖动手柄等专用列保留按控件宽度确定的留白，表头和正文使用同一口径。
3. 网络阶段等采用网格模拟表格的普通列表，表头与数据行使用同样的左右留白，列网格保持一致。
4. 将规则加入 `DESIGN.md` 的 Data Rows 与项目 layout-guidance 的平铺数据行规则。

## 已定决策

- 普通行使用 12 px，紧凑表格使用 8 px。普通行采用现有 4 px 间距阶梯，表格沿用现有单元格密度。
- 留白属于行容器或表格的边缘单元格。条纹覆盖整行，以同一条纹边缘作为测量基准。
- 继续用既有的渲染顺序和行索引决定条纹，虚拟列表占位行沿用原来的零内边距。

## 非目标

- 范围限于现有斑马纹数据行和与之对齐的表头，涉及颜色、圆角、行高、交互、页面留白或新增条纹的改造留给各自需求。

## 验收标准

- URL 结果的普通字段和查询参数均采用 12 px 行内留白。在查看和编辑模式下，标题和末端操作落在同一对齐线上。
- 时间结果、网络阶段、镜像概要、设置中的条纹列表、SSH 配置列表、服务容器选择列表均采用 12 px 行内留白。
- 端口、端口转发、镜像列表及层表、SSH 文件、JSON 对象与数组预览的紧凑表格符合 8 px 边缘留白规范，表头与正文对齐，专用列的宽度和控件仍可用。
- 窄窗口内维持原有的截断、换行和滚动行为。虚拟化、吸顶表头和拖动排序继续沿用原有结构。
- 按项目 `project-validation` 完成适用的项目任务和差异检查。
