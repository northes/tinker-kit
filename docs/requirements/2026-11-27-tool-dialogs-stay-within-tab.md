# 工具弹窗限制在当前标签内容区

## 背景与目标

工具页内弹窗及其遮罩会盖住顶部工作区标签，阻碍用户切换工具。统一让工具弹窗限制在各自标签的内容区内，同时允许用户点击顶部标签切换。

## 需求条目

1. 所有工具页内通过共享 `Dialog` 渲染的弹窗、遮罩和确认框，限制在所属工作区标签的主内容区内，不覆盖顶部标签栏。
2. 弹窗打开时顶部标签仍可点击。切换到其他标签后，弹窗随原标签隐藏；切回原标签后仍保持打开，表单草稿和弹窗状态保留。
3. 此规则适用于现有工具页全部弹窗，包括目标主机/来源管理、SSH 配置管理、工具设置、详情、帮助、创建及确认等弹窗，也适用于后续新增工具页 Dialog。
4. App 级界面（命令面板、任务中心、标签重命名等不属于某个工具标签的弹窗）保持应用级覆盖行为。
5. 复用共享 `Dialog` 与 `ToolSlot` 边界实现，不要求每个工具调用方重复设置 portal、定位或模态属性。

## 已定决策

- 工具页内全部弹窗统一受当前标签内容区约束；App 级弹窗不纳入本次改动。
- 顶部标签可以直接切换；弹窗不因切换而关闭，状态跟随所属标签保留。
- 规范写入 `.agents/skills/layout-guidance/forms-and-controls.md`，由共享 Dialog 默认行为落实，避免新工具遗漏。

## 非目标

- 不改变各弹窗已有的打开、关闭、保存、取消和确认逻辑。
- 不改变 App 级弹窗的显示位置和交互。
- 不调整弹窗内容布局、视觉样式或业务数据流。

## 验收标准

1. 在任一工具内打开管理弹窗、编辑弹窗或确认框，浮层和遮罩均不覆盖顶部标签栏。
2. 弹窗打开时点击另一顶部标签可立即切换；原弹窗随原标签隐藏，切回后仍打开且草稿未丢失。
3. 同一规则覆盖所有现有工具内共享 Dialog，包括嵌套确认框。
4. 命令面板、任务中心和标签重命名等 App 级弹窗仍可覆盖应用窗口。
5. 新建工具页使用共享 Dialog 时自动继承该约束，无需额外接线。
6. 类型检查和项目已有的相关构建检查通过；遵守项目桌面自动化限制。

## 待定问题

无。
