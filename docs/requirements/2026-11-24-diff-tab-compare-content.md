# 差异对比：从工具标签填入与空侧选择

## 背景与目标

用户在开着差异对比标签时，希望直接把 JSON、文本、SSH 文件管理里已有内容放进左右两侧，而不必手动复制粘贴。差异对比左右为空时，也希望像 JSON 输入框一样提示可从已打开的相关标签选择来源。

目标是：在「当前聚焦的标签为差异对比」时，为 JSON / 文本 / SSH 文件管理标签提供「对比内容 → 放入左边 / 放入右边」；并为差异对比空侧提供「已打开的 tab」选择器。

## 需求条目

1. 工作区标签右键菜单：当且仅当**当前聚焦（激活）的标签**为差异对比时，在 **JSON**、**文本**、**SSH 文件管理**三类工具标签上显示二级菜单：**对比内容** → **放入左边**、**放入右边**（左=原文侧，右=修改后侧）。
2. 菜单位置：单独一组，放在「固定 / 取消固定」与「关闭其他 / 重命名」之间；与标签生命周期操作分开。
3. 填入目标：始终填入**当前聚焦的差异对比标签**（只有一个目标）；右键操作**不切换**当前激活标签。
4. 来源内容规则：
   - JSON：仅 **输入** 面板原文，不含结果、格式转换、schema 或其它面板。
   - 文本：编辑器当前全文。
   - SSH 文件管理：须已打开远程文本编辑器；取编辑器当前文本（含未保存修改）；若处于「仅末尾 N 行」模式则取当前可见片段。
5. 菜单可用性：来源文本经 `trim` 后非空才可点「放入左边 / 放入右边」；空白、仅空白字符、SSH 未打开编辑器、编辑器仍在加载或读取失败时，**对比内容**子菜单仍显示但整体禁用（与 SSH「未打开也显示菜单但是禁用」一致）。
6. 覆盖策略：目标侧已有内容时**直接覆盖**，沿用现有差异对比 `filled.before` / `filled.after` 短暂提示，不弹确认。
7. 差异对比空侧提示：任一侧为空（trim 后）时，在该侧编辑器占位显示与 JSON 输入类似的文案：**粘贴文本或从已打开的tab中选择**；仅 **已打开的tab** 带下划线可点，样式对齐 JSON `placeholder` 内 `<open>` 链接。
8. 空侧选择器：点击「已打开的tab」打开 **独立 Command 对话框**（非全局命令面板）；标题区分 **填入左边** / **填入右边**。
9. 选择器列表：仅列出当前工作区中、**标签栏顺序一致**、且**有可对比非空文本**的 JSON / 文本 / SSH（已开编辑器）标签；标签名称与标签栏一致；SSH 条目在标签名后附加当前编辑文件名（如 `主机 · 文件管理 — config.yaml` 或等价清晰格式）。
10. 选择后：将选中标签**当时**的文本写入被点的一侧；若无任何可选标签，显示空状态文案（中英文）。
11. 文案：`zh-CN` / `en-US` 同步新增/修改相关 key；英文语义与中文对齐。
12. 共享逻辑：列举候选标签、判断可否对比、排序与标签栏一致，应集中在可测的纯函数模块（建议 `frontend/src/lib/diff-tab-sources.ts` 或同级），组件只做注册与展示。

## 已定决策

- 「当前打开着 diff」= 当前**激活**的工作区标签为差异对比；非「存在任意 diff 标签」。
- 多 diff 标签场景：用户澄清为只有聚焦 diff 时才出现菜单，故**不需要**再选目标 diff 标签。
- 填入后留在当前差异对比标签。右键来源标签时，该来源标签仍处于后台。
- 空内容：来源没有有效文字时禁用菜单项。
- JSON 仅输入框；覆盖不确认；中英文同步。

## 非目标

- 全局命令面板、托盘、空白标签、设置标签上的同类入口。
- 除 JSON / 文本 / SSH 外的其它工具标签右键对比。
- 从差异对比反向推送到其它工具。
- JSON 结果区、转换区、schema 作为来源。
- 持久化 diff 内容与标签状态到配置。
- Playwright / agent-desktop 自动化验收。

## 验收标准

1. 激活 diff 标签时，右键 JSON/文本/SSH 标签可见「对比内容」二级菜单；激活非 diff 标签时不可见。
2. 有有效来源文本时，「放入左边 / 放入右边」可用，内容进入当前 diff 对应侧，当前标签仍为 diff，并出现原有 filled 提示。
3. 无有效来源（空、SSH 未开编辑器、加载中或读取失败）时，对比内容菜单显示但禁用。
4. JSON 来源仅为输入区内容；文本为全文；SSH 为编辑器当前文本（含未保存与 tail 片段规则）。
5. diff 单侧为空时显示占位与可点「已打开的tab」；弹出选择器标题正确；列表顺序与标签栏一致，仅含三类且有内容的标签；SSH 显示文件名后缀。
6. 选中一项后仅填对应侧；无可选项时空状态可见。
7. `wails3 task common:frontend:run SCRIPT=build` 通过；新增纯函数有单测；`wails3 task test:i18n` 通过。
