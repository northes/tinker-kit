# 主机与地址输入框聚焦时全选

## 背景与目标

各支持 SSH 目标的工具在工具栏左上角放了一个「目标主机 / 来源」下拉输入框，用户点进去往往是为了直接换成另一台主机。现在点进去只会把光标放到点击位置，要替换已有内容得先三击或双击全选，或者逐字删掉。

目标是：这类主机与地址输入框在获得焦点时自动全选已有文字，用户点一下就能直接键入新的主机名替换旧值。

## 需求条目

1. 工具栏的来源 / 目标主机选择器（共享 `SourceCombobox`）在聚焦时全选输入框里的现有文字。覆盖使用它的 6 个工具：镜像管理、文件管理、容器与服务、端口占用、网络测试、端口转发。
2. 网络测试工具栏「目标地址」输入框（`NetworkTestTool` 的 target `Input`）聚焦时全选。
3. 端口转发表单里表示主机的两个输入框（`listenHost`、`targetHost`）聚焦时全选。
4. SSH 配置选择器（`SSHProfileSelect`，出现在各工具的来源 / 目标管理弹窗表单里）同样在聚焦时全选，与第 1 条保持同一套行为。
5. 只处理聚焦时机：首次聚焦（含鼠标点击、键盘 Tab 进入）时全选；已经聚焦后再次点击仍按浏览器默认行为定位光标，保留局部编辑能力。
6. 输入框内容为空或输入框禁用时不产生副作用。
7. 实现集中成一个共享工具函数，不在各工具里重复写同一段选区逻辑。

## 已定决策

- 覆盖范围：凡是工具支持选择 SSH 目标、并提供可编辑的主机 / 地址输入框的，都纳入；普通端口、用户名、路径、搜索框、密码等字段不纳入。
- 交互时机：聚焦时全选，而不是每次点击都全选。
- 共享组件优先：工具栏选择器只改 `SourceCombobox` 一处，不逐个工具打补丁。

## 非目标

- 不改变下拉的筛选、选中、Esc 取消等既有行为。
- 不给普通端口、用户名、路径、搜索、密码等输入框加全选。
- 不新增「清空」按钮或其他输入框附属控件。
- 不新增依赖，不改 Wails bindings、Config 或事件。

## 验收标准

1. 在镜像管理、文件管理、容器与服务、端口占用、网络测试、端口转发里，点击工具栏来源 / 目标主机输入框，框内文字处于全选状态，键入即替换。
2. 网络测试目标地址输入框、端口转发监听主机与目标主机输入框，首次聚焦时全选。
3. 来源 / 目标管理弹窗里的 SSH 配置选择器首次聚焦时全选。
4. 输入框已聚焦后再次点击文字中间，光标定位到点击位置，不会重新全选。
5. `wails3 task` 下现有的类型检查、前端测试与构建通过。

## 待定问题

- 无。
