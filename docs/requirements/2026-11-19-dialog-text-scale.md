# 对话框说明文字字号统一

## 背景与目标

对话框里的说明文字此前没有统一档位：同样是「字段下方提示」，有的 14px（`text-sm`），有的 12px（`text-xs`），网络测试与 SSH 上传还是 10px（`text-[10px]`），原始 JSON 预览是 11px。同一个信息层级在相邻对话框里大小不同，视觉上像是各写各的。

目标是定一套对话框文字标准，写进设计文件，并把现有对话框全部按标准改齐。

## 需求条目

1. 对话框内说明文字（描述、字段提示、状态、错误、小节标签、行内元信息、代码值）统一 12px / 20px 行高。
2. 对话框内不再出现 10px 与 11px；说明文字不使用 14px。
3. 14px 只保留给字段标签与行标题，16px 只保留给对话框标题。
4. `DialogDescription` 组件默认值就是标准值，新增对话框不单独指定说明文字字号。
5. 标准同时写进 `DESIGN.md` 与独立规范文档，逐处对照一并记录。

## 已定决策

- 基准字号：12px（`text-xs` + `leading-5`），与 `DESIGN.md` 的 body 一致。
- 10px 等宽大写小节标签：对话框内一并升到 12px，保留等宽大写与字距作为层级信号。
- 大面板对话框（后台任务、SSH 配置列表、目标主机管理）里的行内元信息也算说明文字，一起升到 12px。
- 落点：`DESIGN.md` 记规则，`docs/design/dialog-typography.md` 记细则与逐处对照。

## 非目标

- 不改工具页（非对话框）里的字号档位。
- 不改对话框宽度、间距、滚动结构和按钮尺寸档位。
- 不改文案内容，不动 locale 资源。

## 验收标准

- 对话框区块内搜索不到 `text-[10px]`、`text-[11px]`。
- 对话框内说明文字只用 `text-xs leading-5`；错误用 `text-destructive`，其余 muted。
- `DialogDescription` 默认值即为标准值，没有对话框再单独覆盖描述字号。
- 前端生产构建（含类型检查）通过；`test:i18n` 通过；改动文件符合 prettier。

## 待定问题

- 无。
