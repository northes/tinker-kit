# 来源下拉只剩一项时回车选中

## 背景与目标

工具栏来源 / 目标主机用的是共享 `SourceCombobox`。Base UI Combobox 默认不自动高亮，输入框回车只确认当前高亮项；没有高亮时只关掉浮层，不改选中值。筛到只剩一台、或列表里本来就只有一台时，用户通常没有按方向键，回车因此进不去。目标是：浮层里可见主机正好一台时，回车直接选中并切过去。

## 需求条目

1. 只改 `frontend/src/components/SourceCombobox.tsx`。镜像管理、文件管理、容器与服务、端口占用、网络测试、端口转发这 6 处共用该组件，一处生效全部生效。
2. 浮层打开，且过滤后的可见主机正好 1 台时，在输入框按回车：选中这台，并走调用方现有的 `onValueChange`（文件管理加载、服务管理切目标、来源记忆等都不改）。底部「管理」行不算这一项。
3. 这台已经是当前选中值时，回车只关闭浮层并清掉筛选，不调用 `onValueChange`，避免文件管理等把列表清空重载。
4. 可见主机是 0 台或多于 1 台时，保持现有回车：有高亮则选中高亮项，没有高亮则只关闭。不要在多于 1 台时自动选排序第一项。
5. 中文输入法组字期间（`isComposing` / keyCode 229）不触发这次选中，沿用现有拦截。
6. 回车仍然不能提交外层表单（端口转发新增转发）。这次选中要拦住 Base UI 的默认回车，避免同一下回车既选中又只关浮层，或把 `onValueChange` 打两次。
7. 浮层未打开时不新增行为。选中后焦点留在输入框，不移进工具主区域。

## 已定决策

- 2026-11-27：用户确认按推荐方案做。范围是共享来源 / 目标主机下拉，不是 SSH 配置选择器，也不是协议、状态等其它下拉。
- 「进入」就是现有选中回调，不额外移动焦点。
- 未过滤时列表里只有 1 台，与筛到只剩 1 台同等对待。
- 已是当前主机只关闭，不重新加载。
- 多于 1 台不猜第一项，仍要方向键高亮再回车。

## 非目标

- 不改 `SSHProfileSelect` 及表单里的 SSH 配置选择器。
- 不改各工具的 `onValueChange` 语义、来源记忆、管理弹窗和数据结构。
- 不把 Combobox 改成始终自动高亮第一项。
- 不新增文案。
- 选中后不把焦点交给搜索框或列表。

## 验收标准

1. 浮层打开且可见主机正好 1 台、且不是当前选中值时，回车选中该主机，浮层关闭，筛选文字清掉，输入框回到该主机名称，调用方切换逻辑执行一次。
2. 可见主机正好 1 台且已是当前值时，回车只关闭浮层，不触发切换或重载。
3. 可见主机多于 1 台且没有高亮时，回车不改变选中值。有高亮时仍选中高亮项。
4. 无匹配时回车不产生选中值。
5. 组字中回车不选中。端口转发里这个输入框回车不提交表单。
6. 上述 6 个工具行为一致，因为它们共用这一组件。
