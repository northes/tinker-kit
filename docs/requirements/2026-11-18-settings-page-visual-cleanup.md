# 设置页视觉收束

## 背景与目标

用户反馈设置页「看起来太混乱」。经 `$impeccable critique` 评审（26/40），在**不改动五个左侧分类 Tab、不删改任何设置项含义**的前提下，收束视觉层级与分组密度，贴近 DESIGN.md「Quiet Toolset」。

## 需求条目

1. **ChoiceGroup（P1）**：分段选项使用紧凑容器（如 `bg-muted` 圆角槽）、按钮 `size="sm"` 或 `xs`，字号与设置标签一致为 `text-xs` 层级；选中态避免满屏 `primary` `default` 实心块，改用工作面/次级高亮（如 `secondary`、`outline`+实底或项目既有分段样式）。
2. **合并视觉分组（P1）**：同一分类内合并相邻单行 `SettingsGroup`，组标题承担领域，行内仍用 `Setting` / `ChoiceGroup`。
   - **常用偏好**：「显示模式、窗口外观（macOS）、语言、字体大小」→ 一组（复用或新增 i18n，如 `settings.appearance`「外观」）。
   - **自动化与通知**：「后台任务通知」与「测试通知」并入一组。
   - **关于**：「项目主页」与「退出」并入「应用」或等价组（复用 `settings.application` 或新增简短组名）。
   - **工作区、工具、托盘识别、开机自启、连接、配置管理、软件更新**等保持逻辑块，仅去掉不必要的单行独占组。
3. **桌面重复分类标题（P2）**：宽度 `min-[701px]` 时隐藏内容区顶部的分类 `<h2>`+底边框；保留 `sr-only` 或无障碍等价，窄屏下拉模式仍可读。
4. **ToolOrderList（P2）**：按 DESIGN.md 隔行淡底（`even:bg-muted/30`、`hover:bg-muted/50`）；显隐图标反映**当前状态**：已启用 `Eye`，已禁用 `EyeClosed`（`aria-pressed` / `aria-label` 不变）。
5. **消除左右同文重复（P1 附属）**：配置导出/导入等行，左侧说明与右侧按钮文案不 100% 复读；按钮可用更短动词（中英文 locale 同步）。
6. **标签宽度预设（P1）**：`ChoiceGroup` 文案统一为 `112px` 无空格（与字号选项一致）；5 项在紧凑槽内可换行但需对齐整洁。

## 已定决策

- 五个分类 Tab 与全部设置项保留；仅视觉分组与样式。
- 允许合并组标题；项没少即可。
- 四类 P1/P2 一次做完。
- 实机对照：优先 agent-desktop 只读截图；权限未开时用户本地验收。

## 非目标

- 不重做五个分类的信息架构。
- 不新增/删除设置字段、不改 Go Config 结构。
- 不改托盘匹配逻辑、工具排序数据模型。

## 验收标准

- `npm --prefix frontend run build` 通过。
- 设置页五个 Tab 均可打开，每项仍可操作且持久化行为不变。
- 桌面宽屏无重复分类大标题；窄屏分类可选仍正常。
- ChoiceGroup 无默认大号 primary 连排；工具列表条纹与眼睛图标符合上述规则。
- zh-CN / en-US 文案同步。
