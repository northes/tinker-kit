# 设置页：托盘识别与通知拆分为独立菜单

## 背景与目标

原「自动化与通知」分类下有两组：`托盘识别`（含可匹配工具）与 `后台任务通知`。用户希望拆成左侧两个独立菜单项，并纠正命名为「托盘识别」（非「右键识别」）。

## 需求条目

1. 移除左侧菜单「自动化与通知」，在原顺序位置插入两项：「托盘识别」「通知」（英文 Tray recognition、Notifications）。
2. 「托盘识别」页仅含：托盘识别开关、可匹配工具列表（行为与现网一致）。
3. 「通知」页仅含：后台任务通知时机、测试通知（行为与现网一致）。
4. 「开机自启」从原自动化组移至「常用偏好」页（与外观、语言、编辑器字号等同页展示）。
5. 分类与菜单命名使用 `settings.categories.trayRecognition` / `settings.categories.notifications`；分组标题与菜单名对齐时避免重复标题（沿用删除窄屏重复分类标题的做法）。

## 已定决策

- 菜单名：托盘识别 + 通知（中英文同步）。
- 开机自启：放在常用偏好。
- 顺序：…工具、托盘识别、通知、SSH、配置管理、关于。
- 分类 ID：`trayRecognition`、`notifications`（移除 `automation`）。

## 非目标

- 不修改托盘匹配、通知发送、自启的底层逻辑。
- 不重命名现有 `settings.trayRecognition`、`settings.taskNotifications` 等分组 key（分组标题可继续用于面板内二级标题，或与菜单同名时省略重复 UI）。

## 验收标准

- 左侧菜单无「自动化与通知」；存在「托盘识别」「通知」且顺序正确。
- 常用偏好中含开机自启开关且可用。
- 托盘识别页无通知相关项；通知页无托盘识别与自启。
- 中英文 `settings.categories.*` key 一致。

## 待定问题

- 无。
