# 圆角内缩外壳

状态：已对齐，待实现。本文是「窗底一色 + 工具区圆角内缩」的结论。实现时以「已定」和「实现约束」为准，不再另做产品决定。

## 背景

参考图是浏览器那种壳：工具栏铺满顶部、和窗底同色，下面的页面四角圆角，左、右、底露出窗底色。TinkerKit 现在的壳是完全方角铺满，需要换成这套外观。

## 已定

### 结构

- 标签条继续铺满窗口顶部，和窗底同一颜色。标签条不进入圆角面板。
- 只有标签条下面的工具内容做成一块四角圆角的整面板，顶边贴住标签条，不留整条横缝。圆角切出的两个上角仍然会露出窗底色。
- 面板在左、右、底各留 8px 缝，三边等宽，缝里露出窗底色。
- 工具页内部布局不动：仍是 Header / Toolbar / Content / Footer 四行骨架，内容区由内部编辑器或列表负责滚动。
- 空白标签、设置页、各工具标签都是同一块圆角面板。
- 对话框、命令面板、任务中心、toast 仍盖住整个窗口，不被圆角面板裁切。

### 颜色

- 窗底和内容用两组颜色，内容继续用现在的工作面色，工具内部不改色。
- 浅色：窗底 `oklch(0.94 0 0)`，内容白（现在的 `--background`）。
- 深色：窗底 `oklch(0.22 0 0)`，内容保持现在的 `oklch(0.145 0 0)`。
- 窗底是新增的一层角色，不复用 `--background`；工具页面的 `bg-background` 语义不变，避免全仓改色。

### 尺寸

- 缝 8px。
- 圆角沿用现有阶梯 `xl`（`--radius` 派生的 0.875rem / 14px），不新增一档半径。
- 圆角面板不加描边、不加阴影，只靠颜色差和圆角分开。

### 交界

- 去掉标签条底下现在那条横贯窗口的分割线。它会横穿两个上圆角，和圆角对不齐。
- 标签条和内容之间没有额外横线，靠窗底色和内容色的差值分界。

### 拖动

- 左、右、底这三条 8px 的缝和标题栏一样可以拖动窗口。

### 选中标签

- 选中标签改用和内容工作面同色（浅色白、深色现有深底），未选中仍只有文字。
- 原因是原来的 muted 底（浅色 0.97）放在窗底灰（0.94）上几乎看不出来。
- 为选中标签底服务的元素（关闭按钮末端的短渐变、标签条横向渐隐）跟着底色一起改。

### 崩溃页

- 应用崩溃时的全屏页不套这层外壳，保持现在铺满工作面。

## 实现约束

- 窗底色只定义在 `globals.css` 的主题变量里，作为新角色 token；组件不硬编码。
- `html` / `body` / `#root` 的底色一并切到窗底色，避免 WebView 边缘或圆角外露出内容色。
- 圆角面板需要裁切内容（`overflow: hidden` + 圆角），工具页内部的滚动容器仍按原有方式工作。
- 圆角面板底部的 8px 缝在面板之外，滚动条和内边距都仍在面板内，不占用这条缝。
- 原生窗口背景色跟随主题设置，避免启动瞬间先闪一次另一种底色。
- DESIGN.md 里「页面结构本身保持方正、不用大面积圆角裁切」这条需要同步改成这套外壳规则，否则下一次改动会把它改回去。
- 崩溃页不套外壳，所以它继续用完整窗口和 `--background`。
- 不涉及文案改动，不需要新增 i18n 资源。
