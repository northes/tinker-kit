# 工作区多标签

状态：已收口，已实现。本文是工作区多标签的产品结论。实现时以「已定」和「由此得出的实现约束」为准，不再另做产品决定。

## 已定

- 这次只改当前这一个窗口里的标签，不新增多窗口。
- 标签是工作区里的工具会话，不是某个工具内部的文档标签。
- 选中一个工具总是再开一份新会话，即使该工具已经有标签。点已有标签才是切换。新标签加在末尾，并成为当前标签。
- 设置也是标签，同时只能有一个，名字就是「设置」，不加序号。再从命令面板选设置，是切到已有的设置标签，不是再开一份。设置标签同样参加 Control+Tab 循环。
- 排列方向由用户选择，记在设置里并持久化。标签条上不放切换。两种都要有：
  - 左侧竖向
  - 顶部横向
- 两种方向都去掉工具侧栏，也去掉标题栏里的侧栏开关。工具目录只通过标签条末尾的 `+` 和命令面板进入。
- 工具的显隐和排序挪到设置页。命令面板只列出启用的工具，顺序跟这份配置走。侧栏的完整 / 仅图标 / 隐藏模式删除。命令面板里的「切换侧栏」也删除。
- 新开标签有三个入口：
  - 标签条末尾的 `+`：新建一个空白标签
  - Command+T（Windows / Linux 为 Ctrl+T）：同上
  - Command+K（Windows / Linux 为 Ctrl+K）：打开命令面板，面板里也有「新建标签」
- 空白标签是工作区里真实的标签，不是弹面板的另一种形式。标签名「新标签」，同时有多个时加序号（新标签 2），与工具标签同一套只增不回收的规则。
- 空白标签的内容区平铺启用的工具：图标加名字的方块，网格自适应，上方一个搜索框，切到空白标签时自动聚焦。网格最后一项是设置，和工具并列，同样参与搜索过滤和回车直开。
- 搜索后只剩一个工具时，在搜索框里回车直接打开该工具。
- 在空白标签里选定工具就地变成该工具，不另开标签，名字随即换成工具名并占用该工具的下一个序号。命令面板里选中工具同理。托盘识别到剪贴板时，当前是空白标签也就地填入。
- 启动时自动给一个空白标签；关掉最后一个标签后同样补一个空白标签，所以不会出现只有 `+` 的空标签条。
- 在命令面板里选中一个工具就新开它的标签。有当前标签时，面板里的其它命令作用于当前标签。
- 没有当前工具时（空白标签、或标签条为空），命令面板列出启用的工具、设置和「新建标签」，不列出「格式化」这类必须有当前标签才做得了的命令。
- 标签顺序就是打开顺序，不能拖动，也不持久化。
- 同一工具的多个标签都显示工具名。第一个不加序号，之后为 JSON 2、JSON 3。序号在本次运行中只增不回收：关掉 JSON 2 再新开，新的叫 JSON 4，JSON 3 保持原名。重启后标签不在了，序号从 1 重新计。
- 关掉标签不询问。方式有三种：点标签上的关闭按钮、Command+W（Windows / Linux 为 Ctrl+W）、鼠标中键。没有右键菜单。
- 只有关掉的是当前标签时，才重新选择当前标签。关掉其它标签时，当前标签不变。Command+W 关掉的总是当前标签。
- 关掉当前标签后激活哪一个，放在设置里。三个值是打开顺序里的前一个、后一个、最近使用的一个，默认最近使用。
- 选「最近使用」时，在还开着的标签里选上次激活最新的那个。打开或切到一个标签时更新它的激活时间。时间只在本次运行的内存里。
- 选「前一个 / 后一个」时，只看打开顺序，不看激活时间。
- 用 Control+Tab 和 Control+Shift+Tab 按打开顺序循环已打开的标签。没有标签或只有一个时，这个快捷键不做事。
- 关掉最后一个补一个空白标签，不退出，也不自动新开工具。没有标签时，Command+W 不退出。
- 横向的每个标签是同一个固定宽度，不随文字变，也不跟窗口平分。名字超出截断。放不下就滚动。
- 纵向标签条宽度可拖动调节，范围 140–360px，存进设置（`tabStripWidth`）并在重启后保留，双击分隔线恢复默认 176px。拖动时标签跟着一起变宽，名称只受标签条内宽限制。
- 是否显示工具图标记在设置里，默认不显示。打开后图标在名称左边。横向打开图标时全部标签一起加宽同一截；纵向的标签宽度由标签条宽度决定，不另外加宽。
- 标签多到放不下时，在标签条里滚动。渐变用现有 `ScrollArea` 的 `scrollFade`：横向 `x`，纵向 `y`。某一侧已经滚到头，那一侧没有渐隐。实现见 `frontend/src/components/ui/scroll-area.tsx` 和 `frontend/src/styles/foundation.css`。
- 关闭按钮的可见方式记在设置里，三个值：一直显示、悬停或当前标签时显示、一直不显示。默认一直显示。设成一直不显示时，仍可用鼠标中键和 Command+W / Ctrl+W 关闭。
- 关闭按钮不占布局位置，三档都浮在标签末端，名称布局不缩短。浮层对齐 SSH 文件收藏项的删除图标（`frontend/src/components/SshFilesTool.tsx` 收藏路径那一行的浮层和渐变），不照搬该行的 `pr-8` 占位。
  - 一直显示：始终浮着，渐变盖住名称末尾。
  - 悬停或当前标签：悬停、键盘焦点进入或该标签是当前标签时浮出。粗指针上这一档保持可见。
  - 一直不显示：任何设备都不显示。
- 不保留标题栏，不再有后退、前进、居中工具名和侧栏开关。名字只出现在标签上。
  - 横向：从左到右是红绿灯、可滚动的标签、固定在可见区域末尾的 `+`、最右的更新提示。这一行可拖动窗口，标签和按钮本身不拖动。`+` 不跟着标签滚走。
  - 纵向：标签在左侧，从红绿灯下方排起，`+` 固定在这条可见区域的末尾。右侧内容顶到窗口最上（红绿灯右侧）。顶部只用一条透明区域拖动窗口。更新提示在窗口右上角。
- 新开或切到一个不在可视区域内的标签时，标签条把它滚进可视区域。`+` 仍然留在原处。
- 没有红绿灯的平台上，标签条从窗口左上角排起，不为窗口按钮留白。横向从左到右是可滚动的标签、固定的 `+`、最右的更新提示。纵向标签从窗口顶部排起。其余规则不变。
- macOS 触控板后退/前进手势关掉，不再切换页面。
- 托盘识别剪贴板后总是新开匹配工具的标签并直接填入，不复用已有标签，也不再询问是否覆盖。当前正在看差异对比时，也不再优先填进当前这份。设置里的「自动覆盖」删除。
- 新开的差异标签仍按现有的「剪贴板填入哪一侧」填入。
- 在设置里禁用一个工具时：没有它的标签就直接禁用。有的话先问要不要关掉这 N 个标签并禁用。确定才一次性关掉这些标签并禁用，不逐个套用激活规则；取消则保持启用。当时看的就是被关掉的标签时，按「关掉后激活哪一个」在剩下的标签里选；当时停在设置页就留在设置。
- 工具内部下钻（例如镜像详情）留在当前标签里，不新开标签。
- 标签和其中的输入只在本次运行的内存里，同一工具的多份标签互不覆盖。退出或刷新后全部丢掉，不因还有未关闭标签而额外询问。
- 每次启动都是空标签条加一个空白标签，不恢复标签列表，也不再按 `devutils.lastPage` 或地址打开工具。`devutils.lastPage` 删除。

## 由此得出的实现约束

这些不是另做的产品决定，而是上面各条要同时成立时的做法。

- 会话的键是标签 id，不是工具 id。现在按工具 id 常驻一份的挂载不能再当会话模型。
- 地址可以反映当前标签，但不是标签列表的来源。镜像详情不再是会换掉整个工作区的路由。
- 激活先后用单调递增的序号，不用墙钟，避免同一时刻分不出先后。
- 旧配置里的侧栏宽度模式、`autoOverwrite`、`devutils.lastPage` 读取时忽略，保存时不再写回。工具显隐和排序仍用现有的 `sidebarTools` 数据，只是入口改到设置页。
- 标签固定宽度在横向是实现时取的常数：无图标一档，有图标一档。纵向宽度来自 `tabStripWidth`，标签宽度等于标签条宽度减去 ScrollArea 为焦点环预留的 8px。两种方向都不做用户能拖的单个标签宽度。
- 当前标签是设置时，命令面板列出启用的工具、设置，以及设置自己的命令，不列出某个工具的命令。
- 被截断的标签名用提示或无障碍名称给出全文。
- 空白标签内容区在居中窄列内排版：工具网格列 `max-width: 52rem`，搜索框 `max-width: 32rem`；窗口更窄时占满可用宽度并保留既有 `px-4` 水平内边距。

## 现状

这些是代码事实，不是方案。

- 窗口是 macOS `MacTitleBarHiddenInset`。红绿灯在左上，自定义标题栏高 38px（加高变体 52px），左侧留白 76px / 96px，这一行可拖动窗口。见 `main.go`、`frontend/src/App.tsx`、`frontend/src/styles/foundation.css`。
- 标题栏现在还有侧栏开关、后退、前进、居中工具名，以及右侧更新提示 `UpdatePill`。
- 应用同时只显示一个页面。路由见 `frontend/src/app/navigation.ts`，最后一次页面记在 `devutils.lastPage`。工具输入没有另存 localStorage，只活在当次挂载的组件状态里。
- 访问过的工具按工具 id 常驻挂载，不用时藏进隐藏 slot。同一工具只有一份实例。挂载逻辑在 `frontend/src/App.tsx`。
- Command+K / Ctrl+K 打开命令面板。面板里既有「打开某个工具」，也有必须有当前标签才做得了的命令。设置入口是 `nav:settings`。另有「切换侧栏」。
- 工具目录在左侧栏。侧栏工具的顺序和显隐由 Go `ConfigService` 持久化。命令面板和托盘识别都会跳过已隐藏的工具。
- 托盘识别剪贴板后跳到匹配工具并填入。设置项 `autoOverwrite` 只被这条路径使用：关掉时先弹窗询问。当前页是差异对比时，优先把内容填进当前这份差异。
- 镜像详情是唯一的子路由（`/image-manager/detail`），现在算另一个页面。
- macOS 打开了 WebKit 的触控板后退/前进手势（`AllowsBackForwardNavigationGestures`）。
- 字体、自动格式化这类偏好已经是全局设置，不跟着标签走。这次不改变它们的归属。
- SSH 文件收藏项的删除图标浮在行末，默认透明，悬停或焦点进入时出现，并用渐变盖住末端文字。该行同时有 `pr-8`，标签不采用这截占位。粗指针上该图标保持可见。
