# 工作区多标签

状态：讨论中，未实现。本文只记录已对齐的决定、当前代码事实，以及还没拍板的问题。

## 已定

- 标签是工作区里的工具标签，不是某个工具内部的文档标签。
- 排列方向由用户选择，两种都要有：
  - 左侧竖向
  - 顶部横向
- 新开工具标签有两个入口：
  - 标签条末尾的 `+`
  - Command+K（macOS；Windows / Linux 为 Ctrl+K，与现在的命令面板快捷键相同）

## 现状

这些是代码事实，不是方案。

- 应用同时只显示一个页面。路由见 `frontend/src/app/navigation.ts`，最后一次页面记在 `devutils.lastPage`。
- 访问过的工具按工具 id 常驻挂载，不用时藏进隐藏 slot。同一工具只有一份实例，切走不丢这份状态。挂载逻辑在 `frontend/src/App.tsx`。
- Command+K / Ctrl+K 打开命令面板。面板里既有工具，也有当前工具和设置的命令。
- 工具目录在左侧栏，宽度模式为完整（232px）、仅图标（56px）或隐藏。标题栏有后退、前进和当前工具名。
- 侧栏工具的顺序和显隐由 Go `ConfigService` 持久化。设置页不是工具。

## 未定

- 同一个工具已经有标签时，再选它是再开一份会话，还是切到已有标签。
- `+` 和 Command+K 是沿用现在的命令面板，还是另做只含工具的选择器。
- 左侧竖向标签和现有工具侧栏怎么共存。
- 方向选择放在哪，以及是否持久化。
- 设置页、托盘、后退前进、命令面板里的非导航命令，在多标签下作用于哪一个标签。
- 关闭、最后一个标签、启动时恢复哪些标签，以及多份同一工具的状态各自存在哪。
